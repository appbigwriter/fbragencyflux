# How to Use a QR Code at Your Counter to Capture Permission-Based Leads

A QR code is a bridge between a physical moment and a digital next step. The benefit, destination and permission request determine whether it works.

## Build the experience

1. State a clear benefit: menu, guide, loyalty offer, appointment or updates.
2. Place the code where the customer has context and time to act.
3. Use a mobile-friendly destination with one primary action.
4. Explain what information is collected and what follow-up will occur.
5. Use a distinct URL or UTM for each placement.
6. Keep the code readable, high contrast and free from glare.
7. Track scans, completed sign-ups, redemptions and unsubscribes separately.

Do not call a scan a customer or a sign-up a sale. Set a baseline, test one message and compare a reasonable window.
