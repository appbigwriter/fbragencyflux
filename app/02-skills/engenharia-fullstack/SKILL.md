# Skill: Engenharia Fullstack & Web Apps

Esta skill guia o desenvolvimento técnico das aplicações e sites dos projetos.

## 🛠️ Stack Tecnológica Recomendada
- **Framework**: Next.js (App Router) ou Vite + React para SPAs.
- **Linguagem**: TypeScript com tipagem estrita e limpa.
- **Estilização**: Tailwind CSS v3/v4 ou CSS Modules / Vanilla CSS com design tokens.
- **Banco de Dados**: Supabase / PostgreSQL ou SQLite local para prototipagem rápida.
- **Componentes**: Lucide Icons, Shadcn-like primitives ou componentes nativos reutilizáveis.

## 🚀 Boas Práticas
- **Zero Secrets Expostos**: Chaves de API e credenciais sensíveis sempre em `.env.local` e nunca commitadas.
- **Responsividade Total**: Layouts fluidos adaptados perfeitamente a Mobile, Tablet e Desktop.
- **Performance & SEO**: Imagens otimizadas, tags semânticas (HTML5), Core Web Vitals otimizados.
