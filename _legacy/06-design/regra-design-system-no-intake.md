# Regra de intake — Design System inicial

## Decisão

Todo novo projeto ou blog da FBR Agency deve ser entregue inicialmente acompanhado do seu Design System base ou de uma referência explícita ao Design System compartilhado adotado pela FBR

O Design System deve entrar no intake junto com o arquivo conceitual do projeto

## Responsabilidade da Íris

Ao receber o briefing, a Íris deve confirmar:

- arquivo ou diretório do Design System
- manifesto ou documentação de tokens
- componentes disponíveis
- tipografia
- cores
- espaçamento
- estados interativos
- regras de imagem
- templates
- limites de adaptação

Se o Design System não for entregue, a Íris deve registrar a ausência como pendência de concepção e não presumir uma identidade visual

## Regras de uso

- o Design System é referência inicial do projeto
- a fonte-base não deve ser alterada para atender um único blog
- cada projeto pode criar uma camada de adaptação própria
- alterações relevantes devem ser registradas como decisão de design
- Théo implementa a adaptação no projeto consumidor
- Íris mantém a referência no pacote conceitual e nos Handoffs
- Gestor Editorial valida coerência com persona, nicho e público
- Sergio aprova mudanças relevantes de identidade

## Critério de aceite

Um intake de projeto só está completo quando contém:

- arquivo conceitual
- Design System base ou referência formal
- escopo visual
- owner da adaptação
- critérios de aceite visual
- Handoff para Íris e owner técnico
